

# Estudos de Python

Repositório criado para registrar minha evolução no aprendizado de **Python**, reunindo códigos desenvolvidos durante as aulas, exemplos separados por assunto e exercícios de fixação.

Meu objetivo é construir uma base sólida na linguagem para avançar nos estudos de **automação, análise de dados e ciência de dados**.

## Conteúdos estudados

Até o momento, o repositório possui exemplos dos seguintes assuntos:

- Sintaxe básica e primeiro programa;
- Variáveis e tipos de dados (`str`, `int`, `float` e `bool`);
- Conversão de tipos;
- Entrada e saída de dados com `input()` e `print()`;
- Formatação e fatiamento de strings;
- Operadores aritméticos, relacionais e lógicos;
- Estruturas condicionais com `if`, `elif` e `else`;
- Laços de repetição com `for` e `while`;
- Controle de laços com `break`, `continue` e `pass`;
- Listas, tuplas, dicionários e conjuntos;
- List comprehension;
- Funções, parâmetros, retorno e escopo de variáveis;
- Argumentos variáveis com `*args`;
- Funções lambda e uso de `map()`;
- Tratamento de exceções com `try`, `except` e `raise`;
- Leitura e escrita de arquivos;
- Importação e criação de módulos e pacotes;
- Uso de módulos da biblioteca padrão, como `math`, `random` e `datetime`.

## Como executar

### Pré-requisito

Tenha o **Python 3** instalado. Para verificar a instalação, execute:

```bash
python --version
```

Dependendo da configuração do sistema, o comando pode ser:

```bash
python3 --version
```

### Executando um arquivo

Abra o terminal na pasta do repositório e informe o caminho do arquivo desejado. Por exemplo:

```bash
python Treinamento/Ex_1.py
```

Para executar a calculadora:

```bash
python Treinamento/Ex_6.py
```

Para estudar estruturas de dados:

```bash
python Estudo/estruturaDados.py
```

Se o seu sistema utiliza `python3`, substitua `python` por `python3` nos comandos.

Alguns programas utilizam `input()`. Nesses casos, o terminal aguardará que um valor seja digitado.
